# Framework Starter
> seymenkonuk/framework ile yeni PHP projeleri oluşturmak için hazırlanmış minimal proje şablonu.

## Açıklama
seymenkonuk/framework ile geliştirme yapmak için hazırlanmış minimal bir başlangıç projesidir.

Framework'ün temel kullanımını gösteren basit bir uygulama yapısı sunar. Amaç, yeni bir projeye hızlı ve temiz bir başlangıç yapmaktır.

## Özellikler

- seymenkonuk/framework entegrasyonu
- Hazır uygulama giriş noktası
- Apache rewrite desteği
- PHPUnit desteği
- PHPStan desteği
- Basit ve genişletilebilir yapı

## Kurulum
```bash
composer create-project seymenkonuk/framework-starter ProjectName
```

## Çalıştırma
```bash
php -S localhost:8080 -t . public/index.php
```

## Erişim
```bash
http://localhost:8080
```
